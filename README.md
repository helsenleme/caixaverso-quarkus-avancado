# caixaverso-quarkus-avancado

Projeto de exercícios avançados com Quarkus 🚀  
Desenvolvido como parte da trilha de aprendizado em Java Quarkus Avançado do ADA Caixa Verso, utilizando Quarkus, Maven e boas práticas de arquitetura REST.

## 📦 Tecnologias utilizadas

- **Quarkus 3.26.2**
- **Java 21**
- **Maven**
- **Hibernate ORM com Panache**
- **PostgreSQL**
- **OpenAPI (SmallRye)**
- **Jakarta Bean Validation**
- **REST Assured (para testes)**

## 🧠 Objetivo do projeto

Este projeto tem como foco o desenvolvimento de uma API REST para gerenciamento de produtos, com validações, documentação automática via OpenAPI e estrutura modularizada.  
A aplicação está preparada para evoluir com autenticação, testes automatizados e deploy em ambiente containerizado.
